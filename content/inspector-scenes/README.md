# Иллюстрации Security Inspector

Семь сцен созданы для CybSec LABS встроенным ImageGen и сохранены локально в JPEG. Изображён вымышленный заказчик.

Общий запрос для всех сцен: «Фотореалистичное корпоративное помещение для учебной игры с интерактивными объектами. Широкий кадр уровня глаз, естественная перспектива, умеренное освещение, стальные и графитовые тона, без логотипов, водяных знаков и элементов интерфейса».

- `meeting.jpg` — переговорная с руководителем продаж и папкой протокола.
- `it.jpg` — кабинет администратора и печатная схема сети.
- `server.jpg` — серверная с двумя стойками.
- `security.jpg` — реестр данных на столе и отчёт на мониторе.
- `office.jpg` — маршрут заказа и рабочее место оператора.
- `legal.jpg` — юрист и открытый регламент.
- `monitoring.jpg` — аналитик и экраны мониторинга.

Координаты интерактивных точек задаются в процентах в `src/enterprise-scenario.js`.
