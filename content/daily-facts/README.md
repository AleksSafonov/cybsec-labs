# Ежедневные материалы

- `collection.js` содержит факты и первоисточники. У каждого факта есть постоянный ID, направление, уровень, краткое объяснение, техническая деталь, применение и ссылки на урок, термин и практику. При правке материала обновите его дату проверки.
- `activities.js` содержит отдельную недельную ротацию четырёх карточек. В каждом наборе последовательно идут термин, задача, миф и вопрос собеседования.
- Коллекция отображается по локальной календарной дате. Чтобы расширить её, добавьте факты в конец и добавьте запись в `dailyFactEditions` с новой датой начала и общим числом фактов. Начинайте новое издание на границе полного цикла предыдущего. Существующие даты, порядок и идентификаторы сохраняйте, чтобы архив и отметки остались прежними.
- Для изменяемых источников задайте срок повторной проверки. После этой даты интерфейс покажет пометку. Перепроверка выполняется редактором, ссылки открываются по запросу пользователя.
- Проверьте изменения через `node tests/smoke.cjs`.
